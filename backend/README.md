# Backend - Banco Semillas API

Importar esta carpeta como proyecto Maven en IntelliJ IDEA. Ejecutar `BancoSemillasApplication`.

- Java: 21
- Spring Boot: 4.1.3
- MariaDB: `localhost:3306/banco_semillas`
- API: `http://localhost:8080/api`

La primera ejecucion crea las tablas, el usuario de demostracion y cuatro semillas iniciales cuando las tablas estan vacias.
